WP-4b thin slice: two assistants on one browser, real server (docs/ASSISTANTS.md §8).
Recorded 2026-11-16 on branch t3/assistants-thin-slice (uncommitted working tree).

How: `pnpm start serve` with LLM_PROVIDER=fake (the offline stand-in), the local recogniser (stt-sherpa parakeet-v2)
and the local voice (Piper en_US-lessac-medium), a temporary data directory whose settings.json (version 4) holds
two assistants on the browser defaults. The sentences were synthesised with `pnpm start say --out` (Piper),
resampled to 16 kHz and streamed in real time as the microphone of a scripted browser tab that owns the audio
(it plays the replies and reports playback). An admin tab collected the live `trace` messages.

Server http://127.0.0.1:18931, protocol 6. Device "Test browser" (evidence-desk), browser defaults: Alpha ("hey alpha"), Bravo ("hey bravo"), nobody answers without a phrase, follow-up 8 s.
Engines: llm fake offline stand-in; stt sherpa parakeet-v2; tts sherpa en_US-lessac-medium
Alpha has the clock and weather modules on (as migrated); Bravo has none. The offline LLM stand-in answers "what time" with the clock tool when it has it, else echoes.

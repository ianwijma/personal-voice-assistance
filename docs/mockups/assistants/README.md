# Assistants mock-ups

`admin.html` and `voice.html` are the two owner-approved mock-ups the assistants and devices UI was built from
(docs/ASSISTANTS.md section 7). They are the **design reference**: the built pages may differ from them. The differences are
listed in docs/ASSISTANTS.md, section 7.3 (where the design differs from the mock-ups) and "Differences in the built UI"
(what was built differently or not at all). Where a mock-up and the code disagree, the code and those lists are right.
`screenshots/` holds the mock-ups as the owner reviewed them, not the built pages (those are in `apps/web/screenshots/`).
